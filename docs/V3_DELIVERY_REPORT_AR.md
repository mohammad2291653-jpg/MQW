**التاريخ:** ١٩ تشرين الثاني ٢٠٢٦ · **الفرع:** `claude/new-session-15tfh8` · **الحالة:** تطوير محلي مُختبَر، **غير منشور**.

## ١. خط الأساس (ما وُجد فعلًا قبل أي تعديل)
- المستودع الحقيقي: Next.js 16.4.6، React 19.2، TypeScript. تشغيل محلي بـ SQLite. الإنتاج على PostgreSQL خاص (Supabase Free) عبر Render Free، بالجلسات المخصّصة نفسها (ليست Supabase Auth). الالتزام المنشور: `35aac55`.
- التخزين: جدول `records` عام ومملوك لكل مستخدم (JSON)، ومعه RLS في PostgreSQL مبني على `mqw.user_id`.
- الاختبارات قبل التعديل (أعدتُ تشغيلها بنفسي): typecheck ناجح · **38/38** وحدة/تكامل · **9/9** متصفح Chromium.
- ملاحظة بيئية: نسخة Playwright في المشروع (1.65) لا تطابق المتصفح المثبّت في الحاوية. أضفت متغيرًا اختياريًا `MQW_CHROMIUM_PATH` في `playwright.config.ts`، ولا يتغيّر شيء إن لم يُضبط.
